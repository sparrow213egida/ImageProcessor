# Image Processor

Консольное приложение для применения графических фильтров к 24-битным BMP‑изображениям без сжатия. Реализована полная загрузка, обработка и сохранение BMP файлов. Поддерживаются шесть фильтров.

---

## Сборка

Для сборки требуется **CMake 3.10+** и компилятор с поддержкой **C++17**.

```bash
mkdir build && cd build
cmake ..
make
```

При сборке автоматически подключается **Google Test** (v1.14.0) для модульного тестирования (опция `BUILD_TESTS` включена по умолчанию).

---

## Использование

```bash
./image_processor <входной_файл.bmp> <выходной_файл.bmp> [фильтры...]
```

Если программа запущена без аргументов или с недостаточным числом параметров, выводится краткая справка.

### Доступные фильтры

| Фильтр | Параметры | Описание |
|--------|-----------|----------|
| `-crop` | `width` `height` (целые) | Обрезает изображение до заданных размеров. |
| `-gs`   | – | Преобразует в оттенки серого. |
| `-neg`  | – | Инвертирует цвета (негатив). |
| `-sharp`| – | Повышает резкость с помощью матрицы [[0,-1,0],[-1,5,-1],[0,-1,0]]. |
| `-edge` | `threshold` (вещественное) | Выделяет границы (переводит в серый, применяет оператор Собеля, пороговая бинаризация). |
| `-blur` | `sigma` (вещественное >0) | Гауссово размытие с заданной сигмой. |

Фильтры применяются **в том порядке**, в котором они перечислены в командной строке.

### Примеры

```bash
# Копирование без изменений
./image_processor in.bmp out.bmp

# Обрезка + градации серого + размытие
./image_processor in.bmp out.bmp -crop 800 600 -gs -blur 0.5

# Негатив и выделение границ
./image_processor photo.bmp result.bmp -neg -edge 0.3
```

## Архитектура проекта

Проект состоит из следующих модулей:

| Файл | Назначение |
|------|------------|
| `bmp_common.h` | Вспомогательные функции для нормализации и преобразования цветовых компонент (double ↔ unsigned char). |
| `bmp_structures.{h,cpp}` | Классы `Pixel`, `PixelArray`, `BMPHeader`, `DIBHeader`, `BmpFile`; функции чтения/записи BMP (только 24‑бит, BI_RGB). |
| `filters.{h,cpp}` | Классы фильтров со статическими методами `Apply`. |
| `image_processor.cpp` | Точка входа – разбор аргументов командной строки, применение фильтров, сохранение результата. |
| `test_image_processor.cpp` | Модульные тесты на Google Test. |

Фильтры реализованы как **отдельные классы со статическими методами** (без иерархии наследования), что упрощает код и делает его легким для расширения.

Внутреннее представление изображения – матрица пикселей, каждый пиксель хранит вектор вещественных значений компонент (RGB) в диапазоне [0,1].

## Тестирование

Для запуска модульных тестов:

```bash
make test
```

или непосредственно:

```bash
./test_image_processor
```

Тесты покрывают:
- вспомогательные функции преобразования;
- каждый фильтр на простых искусственных изображениях (постоянный цвет, граница, маленькие размеры);
- корректность изменения размеров и паддинга при сохранении.

---

## Обработка ошибок

Все ошибки перехватываются через исключения и выводятся в `stderr` с понятным сообщением:

- входной файл не найден или не может быть открыт;
- файл не является BMP или имеет неподдерживаемый формат (сигнатура, глубина цвета, сжатие);
- неверное количество или тип параметров фильтра;
- неизвестный фильтр;
- ошибки записи выходного файла.

Программа не падает на некорректных данных – завершается с кодом возврата 1 и сообщением об ошибке.

---

## Ограничения

- Поддерживаются только **24‑битные** BMP без сжатия (BI_RGB) и с DIB-заголовком `BITMAPINFOHEADER`.
- Размер изображения ограничен доступной оперативной памятью.
